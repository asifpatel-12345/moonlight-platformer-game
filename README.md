# Moonlight Castle Adventure (2D Python Platformer)

A 2D side-scrolling platformer game built in Python using `pygame`, featuring procedural vector graphics, synthesized sound effects, multi-level progression, and physics-based platforming.

## Features
- **Complete Game States:** Start Screen, Active Gameplay, Pause Menu (`P`), Game Over, and Victory Screen.
- **Physics & Controls:** Smooth horizontal movement, gravity, collision detection, and jump mechanics (`Arrow Keys` / `WASD` / `Space`).
- **HUD & Scoring:** Real-time Health (Hearts), Coin Counter, Score Tracker, and Level Indicator.
- **Zero External Assets:** All sprites, backgrounds, animations, and retro audio cues are generated procedurally in Python.
